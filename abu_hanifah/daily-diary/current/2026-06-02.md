### Pembaikan Pepijat Skor Kuiz (21/20) & Set Semula Sesi (Reset Session)
**Masa**: Pagi

Tuan melaporkan masalah di mana markah keputusan kuiz menjadi salah (seperti `21/20` atau melebihi 100%) apabila menggunakan butang "Ulang Soalan 1".

**Punca Masalah:**
1. Sebelum ini, setiap kali jawapan betul dihantar, backend akan secara langsung melakukan `increment('correct_count')` pada baris sesi kuiz. Apabila pengguna mengulang kuiz, jawapan lama tidak dipadamkan dalam pangkalan data dan jawapan betul yang diserahkan semula terus menambah nilai `correct_count` secara berulang kali.
2. Tiada fungsi untuk menetapkan semula (reset) rekod jawapan terdahulu bagi sesi semasa dalam pangkalan data apabila pengguna memulakan semula kuiz dari Soalan 1.

**Tindakan Pembaikan:**
1. **Pengiraan Skor Dinamik**: Mengubah logik di `QuizService.php` agar nilai `correct_count` dikira secara dinamik menggunakan `count()` bagi semua baris `QuizAnswer` yang mempunyai `is_correct = true` untuk sesi tersebut. Ini menjamin skor tidak akan melebihi had maksima soalan (20/20).
2. **Endpoint Reset Sesi (`/api/quiz/{sessionId}/reset`)**:
   * Membina fungsi `resetSession` di backend untuk menetapkan semula status sesi kepada `in_progress`, `correct_count` ke `0`, dan membersihkan rekod jawapan terdahulu (`user_answer = null`, `is_correct = false`, `revealed = false`).
   * Menetapkan `is_correct = false` (bukannya `null`) semasa reset bagi mematuhi kekangan integriti `NOT NULL` di pangkalan data SQLite/MySQL.
3. **Pematuhan OLAC (Rule #5)**: Mengemas kini semua fungsi berkaitan kuiz (`submitAnswer`, `revealAnswer`, `completeSession`, `resetSession`) untuk menapis rekod secara ketat menggunakan `user_id` pengguna semasa yang disahkan bagi menghalang sebarang kerentanan akses tidak sah (IDOR).
4. **Integrasi Frontend**: Menyepadukan panggilan API `/api/quiz/{sessionId}/reset` pada butang "Ulang Soalan 1" di `page.tsx` sebelum menetapkan semula state React tempatan.
5. **Penstabilan Urutan Soalan (`orderBy('id')`)**: Menyelesaikan masalah di mana soalan tersusun semula (shuffled) selepas reset. Menambah klausa `orderBy('id')` pada hubungan `answers()` di `QuizSession.php` untuk menjamin urutan soalan yang konsisten dan stabil.
6. **Penambahan Unit Test**: Menambah kaedah pengujian `test_user_can_reset_quiz_session` di dalam `QuizEngineTest.php` dan semua ujian (11 kes ujian) lulus dengan cemerlang.
7. **Push ke GitHub**: Kod pembaikan stabil berjaya ditolak ke GitHub (Commit: `e7fc46b`).
