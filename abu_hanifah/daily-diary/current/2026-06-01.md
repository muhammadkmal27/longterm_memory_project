### Pembaikan Pepijat Apostrof Pintar (Smart Punctuation Bug)
**Masa**: Petang (Sesi Lanjutan)

Ditemukan isu di mana jawapan pengguna bertukar menjadi salah walaupun ejaannya kelihatan sama seperti jawapan betul di telefon pintar (`I don't understand.`).

**Punca Masalah:**
* Papan kekunci telefon pintar menukar apostrof standard `'` (U+0027) kepada **Modifier Letter Apostrophe `ʼ` (U+02BC)** secara automatik.
* Dalam regex pembersihan `[^\w\s]`, aksara `ʼ` (U+02BC) diklasifikasikan oleh Unicode sebagai huruf (*Letter Modifier*), bukannya tanda baca. Jadi ia **tidak dibuang** oleh sistem, manakala `'` (U+0027) dalam pangkalan data **dibuang** kerana ia adalah tanda baca. Ini menghasilkan perbandingan string yang tidak sepadan (`idonʼtunderstand` vs `idontunderstand`).

**Tindakan Pembaikan:**
* Mengemas kini fungsi normalisasi di **Rust Quiz Engine** (`main.rs`), **Laravel fallback service** (`QuizService.php`), dan **Frontend Next.js** (`page.tsx`) untuk menukar semua simbol apostrof unik (`’`, `‘`, `ʼ`, `` ` ``, `´`, `՚`, `＇`) kepada apostrof standard `'` terlebih dahulu sebelum membersihkan tanda baca.
* Membina semula (*rebuild*) dan memulakan semula kontena Docker `quiz-engine` di localhost.
* Kod pembaikan berjaya ditolak ke GitHub untuk pengemaskinian di pelayan pengeluaran.

### Penyelarasan Aliran Susun Atur Kad Kuiz (Vertical Layout Center vs Top)
**Masa**: Malam

Tuan meminta agar kad kuiz tidak berada di atas skrin secara tetap dari awal, kerana ia kelihatan pelik. Reka bentuk baharu diselaraskan secara dinamik:
1. **Keadaan Asal (Sebelum Semakan)**: Kad kuiz diletakkan di tengah-tengah skrin secara menegak (`items-center`) untuk penampilan yang seimbang dan kemas apabila pengguna mula-mula masuk ke halaman kuiz.
2. **Keadaan Hasil / Semakan**: Sebaik sahaja pengguna menekan butang "Semak Jawapan" atau "Bagi Jawapan" (iaitu apabila ruang jawapan dan latihan menulis dibuka ke bawah), kad kuiz akan bergerak ke bahagian atas (`items-start pt-4 sm:pt-[12vh]`). Bagi mengelakkan limpahan skrin dan visual yang bertindih pada mudah alih, saiz teks tajuk kuiz diselaraskan (`text-xl sm:text-2xl`) dan padding kad dikecilkan secara dinamik (`p-3 sm:p-4`). Ini memastikan keseluruhan elemen latihan menulis kelihatan dengan jelas tanpa melompat keluar dari skrin.

### Pembaikan Ralat Anjakan Susun Atur Bar Skrol (Scrollbar Layout Shift Bug)
**Masa**: Malam (Sesi Lanjutan)

Apabila pengguna menekan butang/tetingkap "Semua Level", senarai level akan memanjang ke bawah dan menyebabkan bar skrol menegak (vertical scrollbar) muncul di sebelah kanan pelayar. Ini menolak keseluruhan susun atur elemen (termasuk header dan kad kuiz) sedikit ke kiri secara mengejut.

**Punca Masalah:**
Atribut `html { scrollbar-gutter: stable; }` telah dipadamkan daripada fail CSS sebelum ini. Tanpa ketetapan ini, ruang untuk bar skrol tidak ditempah apabila skrin tidak melimpah, menyebabkan anjakan piksel mendatar (layout shifting) berlaku semasa bar skrol muncul atau hilang.

**Tindakan Pembaikan:**
* Memulihkan peraturan CSS `html { scrollbar-gutter: stable; }` ke dalam `frontend/src/app/globals.css` bagi memastikan ruang untuk bar skrol sentiasa ditempah, sekali gus menstabilkan kedudukan mendatar susun atur.
* Perubahan disahkan melalui pengujian tsc dan ditolak ke GitHub.
