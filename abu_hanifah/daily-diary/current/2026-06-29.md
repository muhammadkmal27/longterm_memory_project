## 🎯 Fokus Hari Ini: Integrasi Pengiklanan & Jejaki Prestasi (Ads & Pixel)
Tuan telah mengarahkan saya untuk merekodkan segala konfigurasi berkaitan kempen pengiklanan (Ads Campaign), tetapan Facebook Pixel, dan Conversions API (CAPI) bagi projek **Vocabulary / Bijak English**. Rekod ini disimpan supaya Tuan mudah membina kempen pengiklanan pada masa akan datang.

### 1. Facebook Pixel (Bijak English Pixel)
- **Komponen Utama**: Teras penjejakan (*tracking*) klien diletakkan di dalam `frontend/src/components/FacebookPixel.tsx`.
- **Fungsi Global**: 
  - `fbq('init', pixelId)` dihidupkan menggunakan ID dari `NEXT_PUBLIC_FACEBOOK_PIXEL_ID` (dalam fail `.env`).
  - `fbq('track', 'PageView')` diaktifkan secara automatik setiap kali *route* / halaman Next.js berubah menggunakan `usePathname` dan `useSearchParams`.
  - Fungsi utiliti tambahan `trackFbEvent(name, data)` dieksport supaya kita boleh menjejaki peristiwa penting (*event tracking*) seperti klik butang 'Beli' atau 'Log Masuk' dari mana-mana halaman.

### 2. Conversions API (CAPI)
- Memandangkan pelayar web moden (seperti Safari iOS) kini menyekat *cookies* (Cookie-less) melalui ciri perlindungan privasi (ITP), **Conversions API (CAPI)** memainkan peranan sangat penting.
- **Logik Pelaksanaan**: Berbeza dengan Pixel biasa (yang berjalan pada *browser* pengguna), CAPI membolehkan pelayan (*backend* Laravel kita) menghantar peristiwa/data terus ke pelayan Facebook (Server-to-Server).
- **Faedah Utama**: Data pembelian/langganan dari Stripe atau ToyyibPay dihantar dengan tepat terus dari pelayan kita, menyelesaikan isu *ad-blocker* atau ralat rangkaian pengguna yang menggagalkan penjejakan Pixel tradisional.

### 4. Panduan Langkah-Demi-Langkah (Step-by-Step) Setup Facebook Ads

Berdasarkan perbualan lepas, ini adalah rekod tepat cara kita menyiapkan kempen iklan (Ads) untuk dua jenis strategi yang berbeza:

#### Strategi A: Kempen Jualan Langganan (SaaS - Cth: Bijak English)
Tujuan: Mengajak pengguna terus melanggan melalui laman web.
1. **Langkah 1: Tetapkan Bajet (Campaign Level)**
   - Pilih **Campaign budget** (CBO - *Campaign Budget Optimization*). Ini membolehkan AI Facebook menguruskan perbelanjaan dengan optimum.
   - Tetapkan bajet kepada **Daily budget** (cth: RM 5.00).
   - Biarkan kotak *Cost per result goal* **kosong** (strategi *Highest Volume*).
2. **Langkah 2: Tetapkan Laman Web & Pixel (Ad Set Level)**
   - *Conversion Location*: Pilih **Website**.
   - *Dataset/Pixel*: Pilih **Bijak English Pixel**. (Rujuk nota *Troubleshooting* di bawah jika Pixel tidak muncul).
   - *Conversion Event*: Pilih **Purchase** atau **Complete Registration**. Hiraukan amaran oren (event belum dipasang) kerana ia akan hilang selepas pelanggan pertama masuk.
   - *Audience & Schedule*: Abaikan tetapan umur secara manual dan gunakan *Advantage+ Audience* (AI pintar). Biarkan *End date* kosong supaya iklan berjalan berterusan (mudah ditutup secara manual).
3. **Langkah 3: Masukkan Gambar & Butang Website (Ad Level)**
   - Namakan iklan (cth: "Gambar Promosi 1").
   - *Ad Creative*: Tekan **Add Media > Add Image**.
   - *Primary Text*: Ayat promosi di ATAS gambar.
   - *Headline*: Tajuk BOLD di BAWAH gambar.
   - *Website URL*: Masukkan pautan (cth: `https://bijakenglish.imat.my`).
   - *Call to action*: Pilih **"Learn More"** atau **"Sign Up"**.
   - Tekan **Publish**!

#### Strategi B: Kempen Agensi Servis (Cth: SaaS House)
Tujuan: Menarik prospek (leads) ke WhatsApp untuk perbincangan peribadi.
1. **Langkah 1: Objektif Engagement (Bukan Traffic)**
   - Wajib pilih **Engagement** (ikon mesej). Jangan pilih *Traffic* menggunakan pautan `wa.me` kerana ia akan membakar bajet dengan "klik hantu".
   - Pilih **Manual engagement campaign** (supaya AI tidak memaksa kempen masuk ke Messenger/Instagram DM).
2. **Langkah 2: Halakan ke WhatsApp Sahaja (Ad Set Level)**
   - *Conversion Location*: Pilih **Messaging Apps**.
   - Tandakan kotak **WhatsApp** dan buang tanda (untick) pada Messenger dan Instagram.
3. **Langkah 3: Bajet & Penyiapan**
   - Tetapkan bajet harian dan teruskan ke bahagian muat naik gambar serta *copywriting* memujuk.

#### 💡 Nota Penting: Troubleshooting Pixel Hilang (Sistem Meta)
Jika ruangan *Dataset* menyuruh Tuan menekan *"Create dataset"* padahal Pixel sudah dibina:
- **Punca**: Akaun Iklan (Ad Account) dan Pixel (Dataset) belum dihubungkan.
- **Penyelesaian Pantas**:
  1. Buka pautan: `https://business.facebook.com/settings/datasets`.
  2. Klik pada nama Pixel (Cth: Bijak English Pixel).
  3. Klik tab **Connected assets** di bahagian tengah.
  4. Tekan butang **Assign assets** (di sebelah kanan).
  5. Tandakan (Tick ✅) pada nama Akaun Iklan Tuan, dan tekan **Add/Save**.
  6. Kembali ke tab Ads Manager, **Refresh (F5)**, dan Pixel tersebut akan muncul!
