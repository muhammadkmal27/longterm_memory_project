### Panduan Teknologi Muat Naik (Upload/Deployment)
**Masa**: Petang

Sebagai rujukan masa depan, berikut adalah teknologi yang kita gunakan untuk deploy aplikasi Vocabulary secara automatik ke server Proxmox LXC 201:

1. **GitHub Actions**: Membina Docker image dan menolak (push) ke GHCR apabila ada kod baharu di branch `main`.
2. **GitHub Container Registry (GHCR)**: Berperanan sebagai repositori simpanan imej backend & frontend (`ghcr.io`).
3. **GitHub Self-Hosted Runner**: Ejen yang dipasang terus di dalam server LXC 201 untuk mendengar dan menjalankan tugasan deployment tanpa sambungan SSH luar.
4. **Docker & Docker Compose**: Menarik imej dari GHCR dan melancarkan container di server.
5. **Cloudflare Tunnel (Zero Trust)**: Menghubungkan domain `bijakenglish.imat.my` terus ke container Nginx secara selamat tanpa membuka port firewall server.
